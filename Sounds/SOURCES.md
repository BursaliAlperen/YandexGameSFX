# CC0 sound sources

All source packs used by this build are marked CC0 on OpenGameArt.org:

- 80 CC0 creature SFX — rubberduck
- 80 CC0 RPG SFX — rubberduck
- 100 CC0 SFX — rubberduck

Source pages:
- https://opengameart.org/content/80-cc0-creature-sfx
- https://opengameart.org/content/80-cc0-rpg-sfx
- https://opengameart.org/content/100-cc0-sfx

The workflow converts the source audio to MP3 for use in the archive.
